# Experiments

This folder stores curated Kaggle notebook/script snapshots used to reproduce the report tables.

- `kaggle_runs/` contains one folder per finalized experiment setting.
- Each experiment folder keeps its notebook, exported Python source, and a short README when available.
- Large outputs, checkpoints, logs, and datasets are intentionally excluded from the repository.

For the simplest entry point, start with `notebooks/KAGGLE_QATACOV19_ALL_IN_ONE.ipynb`.
